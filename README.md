# Zombie — 30초 CG 단편

야간 도시 거리에서 좀비가 표적을 포착하자 초고속(최고 약 9.6 m/s ≈ 35 km/h)으로 질주해
덮치고, 목을 물어뜯어 씹는 장면을 담은 30초 영상입니다. Blender 4.5 (Cycles)로 **전부 절차적으로**
만들었습니다. 키프레임을 손으로 찍지 않았고, 모든 동작은 코드로 계산했습니다.

- 결과물: [`output/zombie_30s.mp4`](output/zombie_30s.mp4) (1280×720, 24fps, 30초, 스테레오 사운드)

## 사실감을 위해 한 일

**인체 / 외형**
- MakeHuman CC0 베이스 메시(1.3만 버텍스)와 모프 타깃으로 체형을 만들었습니다. 좀비는 마르고 볼이 꺼지고
  눈이 움푹 들어간 체형, 희생자는 평범한 체형입니다. 163본 리그와 스킨 웨이트, 눈·치아·혀·눈썹·속눈썹·
  머리카락·의상 프록시(.mhclo)도 직접 피팅했습니다. 애드온 코드는 실행하지 않았고 **데이터 파일만 파싱**합니다
  (`scripts/mhload.py`).
- 좀비 피부 셰이더: 채도를 뺀 회녹색 사체 톤, 시반(멍) 얼룩, 곡률 기반 때, 관자놀이·목·팔뚝의 정맥, 검게
  꺼진 눈두덩, 청색증 입술, 상처, 입가와 턱에서 흘러내린 말라붙은 피, 탁한 백탁 안구, 누렇게 변색된 치아.
- 피 묻은 찢어진 흰 티셔츠, 피부 SSS, 젖은 생피(코트 레이어)가 시간이 지나며 번지도록 했습니다.

**질주 (`scripts/anim.py`)**
- 직접 구현한 해석적 2-본 IK로 **발이 지면에 고정**됩니다. 지지기 동안 발은 월드 좌표에 박혀 있어
  미끄러짐이 없습니다.
- 속도에 따라 케이던스(1.55→2.27 Hz)와 접지 비율(0.52→0.24)이 바뀌어 체공 구간이 있는 스프린트가 됩니다.
  힐 리커버리, 하이 니 드라이브, 앞발 착지, 토오프 시 발목 저굴과 발가락 굴곡, 골반 상하·회전·롤,
  상체 반대 회전을 넣었습니다.
- 0→9.6 m/s 폭발적 가속(시정수 0.55초), 25~42° 전경사, 표적에 고정된 머리, 할퀴듯 휘두르는 팔과 갈고리 손가락.
- 표적 포착: 경련하던 머리가 0.09초 만에 홱 돌아가고, 몸통 비틀기 → 피벗 스텝 → 웅크림(예비동작) → 출발.

**물기와 씹기**
- 덮치기: 1.5m 앞에서 비스듬히 도약해 가슴으로 부딪히고, 양팔로 몸통을 감싸 안습니다. 희생자는 발을 축으로
  뒤로 넘어가고(맞은 반동 + 중력 가속), 좀비는 희생자의 몸 좌표계에 붙은 채 함께 쓰러져 무릎으로 착지합니다.
- 먹는 자세: 희생자 골반 위에 무릎을 꿇고 걸터앉습니다. 골반·입·시선 목표는 희생자 몸 좌표계로 정하고,
  상체 숙임 각도는 매 프레임 황금분할 탐색으로 풀어서 입이 목의 물기 지점에 약 1cm 이내로 닿게 합니다.
  팔꿈치를 굽혀 어깨를 누르고, 한 손으로 머리를 밀어 목을 드러나게 합니다.
- 물기 → 조이기 → 머리를 흔들며 찢기(4~6.5 Hz) → 뒤로 당겨 뜯어냄 → 고개를 들고 씹기 → 삼킴 → 재공격.
- 씹기 사이클(1.55 Hz)은 천천히 벌리고(60%) 빠르고 강하게 다무는(40%) 비대칭이고, 좌우 맷돌질(턱 요),
  아랫입술·윗입술 움직임, 눈꺼풀 반쯤 감기, 삼킬 때 목 움직임을 넣었습니다. 살점은 씹을수록 작아집니다.
- 희생자는 비명을 지르며 좀비의 어깨를 밀어내고 발버둥치다가, 살점이 뜯기는 순간 쇼크로 팔이 바닥에
  떨어지고 점점 힘이 빠집니다(IK 손이 좀비 어깨에 실제로 닿음).
- 피 효과: 상처/입가 혈흔 확산, 찢을 때 튀는 핏방울(탄도 계산과 속도 방향 늘어남), 턱에서 떨어지는 핏방울, 커지는 피 웅덩이.

**촬영 / 룩**
- Cycles 패스트레이싱, 모션 블러(180° 셔터), 피사계 심도, 핸드헬드 카메라 흔들림.
- 젖은 아스팔트 물웅덩이 반사, 나트륨 가로등(하나는 깜빡임), 불 켜진 창문, 밤하늘 HDRI.
- 컴포지터: 미스트 패스 안개, 포그 글로우, 렌즈 색수차, 컬러 그레이딩, 비네팅. ffmpeg에서 필름 그레인을 더했습니다.
- 사운드(`scripts/audio.py`)도 절차적으로 합성했습니다. 발자국은 실제 발 착지 시점과 동기화되고, 그 밖에
  가로등 웅웅거림, 좀비 숨소리·으르렁·비명, 충돌음, 물기·찢기·씹기·삼키기 효과음, 긴장감 드론이 들어갑니다.

## 재현 방법

```bash
ASSETS=$PWD/.assets bash scripts/fetch_assets.sh          # bpy(PyPI) + CC0 에셋 다운로드
.assets/venv/bin/python scripts/build_scene.py .assets .assets/final.blend
.assets/venv/bin/python scripts/render.py -- .assets/final.blend 1 720 .assets/frames
.assets/venv/bin/python scripts/dump_timing.py .assets .assets/timing.json
.assets/venv/bin/python scripts/audio.py .assets/timing.json .assets/audio.wav
bash scripts/encode.sh .assets/frames .assets/audio.wav output/zombie_30s.mp4
```

빠른 미리보기는 `build_scene.py .assets out.blend preview`로 만들 수 있습니다(640×360).
